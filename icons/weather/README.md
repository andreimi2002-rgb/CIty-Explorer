# Weather icons

The official symbol set used with MET Norway's Locationforecast (`symbol_code`, e.g. `partlycloudy_day`).

- Source: https://github.com/metno/weathericons, folder `weather/svg`, commit `89e3173756248b4696b9b10677b66c4ef435db53`, downloaded 21 October 2026.
- Licence: MIT, Copyright (c) 2015-2017 Yr, text in [`LICENSE`](LICENSE).
- `legend.csv`: MET's list of symbol codes with English names (the i18n keys `weather.symbol.*` follow it).

Shown with `<img>`, so the SVGs cannot run scripts. MET's own codes include the spellings `lightssleetshowersandthunder` and `lightssnowshowersandthunder`; they are kept as published.
